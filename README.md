# IPT Smart Landing Page

Responsive landing page for IPT Smart, built with Vite, HTML, SCSS, and vanilla JavaScript.

## Tech Stack

- Vite
- SCSS (Sass)
- Vanilla JavaScript (ES modules)
- Static assets (images and custom fonts)

## Project Structure

```text
.
├── index.html
├── js/
│   ├── main.js
│   ├── phone-carousel.js
│   └── track-recharge.js
├── scss/
│   ├── base/
│   ├── components/
│   └── main.scss
├── images/
├── fonts/
└── package.json
```

## Getting Started

### Prerequisites

- Node.js 18+ (recommended)
- npm

### Installation

```bash
npm install
```

### Development

Start the local development server:

```bash
npm run dev
```

### Build

Create a production build:

```bash
npm run build
```

### Preview Production Build

Serve the built files locally:

```bash
npm run preview
```

## Features

- Mobile-first responsive layout
- Hero phone carousel animation
- Track & Recharge section scroll/visibility-driven animation
- Modular SCSS component architecture
